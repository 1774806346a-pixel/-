# 首集大纲与永久删除设计

## 目标

让首集生成在剧本请求前自动形成故事大纲，并为项目列表提供可确认的永久删除能力。

## 首集生成

当当前集数为第 1 集且大纲输入为空时，工作区先使用当前模型生成一份纯文本故事大纲。大纲生成成功后立即回填大纲输入框，并将其作为剧本生成请求的一部分。剧本保存成功时，大纲进入版本的 `generationContext.outline`，因此后续集数可以从最近版本恢复并复用；大纲或剧本任一步失败都停止流程并显示具体错误。

已有大纲时不重复生成，用户可以手工修改后直接生成剧本。第 2 集及以后保持现有流程。

## 永久删除

项目列表每个项目行提供删除动作。用户确认后调用新的 Tauri `delete_project_permanently` 命令；后端在一个事务中删除该项目的原稿、剧本版本、故事大纲/故事 Bible 及项目记录。删除当前项目后回到首页，删除其他项目后仅刷新列表。删除失败时保留项目并展示错误。

## 错误与兼容性

大纲生成复用现有 `ModelAdapter`、错误格式化和取消控制器。永久删除沿用现有 Tauri repository 边界，不把数据库细节暴露给 React。旧项目数据不需要迁移。

## 验收标准

- 第 1 集空大纲点击生成会产生一次大纲请求和一次剧本请求。
- 大纲内容显示在大纲输入框，并随首集版本保存。
- 已有大纲或非首集不会额外触发大纲请求。
- 项目删除必须二次确认，确认后项目及其关联记录均不可在列表和项目图中恢复。
- 模型失败、删除失败均显示具体错误信息。
