# 双入口按集短剧剧本工作台设计

## 目标

将当前工作台收敛为两个直接生成剧本的创作入口：

- 创意中心：一句话创意生成短剧分集剧本。
- 剧本演练：小说、章节、大纲或已有剧本按短剧模板改编为分集剧本。

暂时移除故事圣经、版本中心、剧本诊断、资产、分镜与提示词等后续阶段，保留按项目保存原始输入与分集剧本的最小闭环。

## 用户流程

首页显示两个并列入口卡片。点击入口后进入该项目的按集创作工作台，工作台包含：

1. 输入来源编辑区。创意中心使用一句话创意；剧本演练使用原文。
2. 项目级主体大纲编辑区。主体大纲在各集之间共享。
3. 目标集数选择器。默认第 1 集，允许创建或切换到任意正整数集数。
4. 单集时长设置。默认 90 秒，限制在合理的短剧时长范围内。
5. 前集参考区。生成第 2 集及以后时，展示上一集剧本，并允许勾选更早集数作为参考。
6. 生成按钮、取消按钮、状态信息和剧本结果区。

第 1 集上下文为“入口输入 + 主体大纲”。后续集上下文为“入口输入 + 主体大纲 + 选中的前集剧本”，默认选中上一集。每个集数单独保存，重新生成创建新草稿或替换当前集草稿前必须明确操作，不覆盖其他集。

## 提示词与输出

统一使用短剧模板改编提示词。提示词必须包含：

- 先读取并遵循 `references/format-template.md`；若运行环境无法读取文件，则使用应用内置的同版本模板文本。
- 保留顶层结构：`【本次改编】`、`【剧本信息】`、`【主要人设】`、`【故事梗概】`、`## 第X集`、`【第X集 改编处理】`、`【第X集 质量自检】`。
- 场次格式为 `### 集-场次`、地点/日夜/内外、人列表；动作行以 `△` 开头；每句对白带情绪括号。
- 单集 2-4 场、一个独立冲突、一次反转和明确结尾钩子；优先可视行为，不复述原文。
- 后续集必须说明如何承接前集结尾、主体大纲和已锁定事实。

模型仍返回结构化 JSON，先经现有剧本 Schema 与格式规则校验，再渲染为 Markdown。生成失败不保存剧本版本，只保留可重试的任务状态和错误信息。

## 数据与状态

项目保留现有本地持久化机制。新增/调整的分集记录至少包含：项目 ID、入口类型、集数、输入快照、主体大纲快照、参考集数、模型与提示词版本、生成状态、Markdown 正文、创建/更新时间。原始输入保持不可变；用户修改输入时写入新快照。

UI 使用单一创作工作台状态：`idle -> ready -> running -> succeeded/failed/cancelled`。切换集数不会丢失已保存内容；未保存变更在切换或离开前提示用户。

## 页面边界

保留：项目列表/创建、两个入口、按集工作台、分集剧本列表、剧本查看与导出。

移除当前导航及其页面：输入与解析、故事圣经、版本中心、剧本诊断、资产、分镜与提示词。模型设置保留为全局设置入口，因为生成仍依赖模型配置。

## 验证

- 单元测试覆盖：集数上下文拼接、模板提示词、上一集默认引用、输入快照隔离、失败不落库。
- 集成测试覆盖：创意中心和剧本演练各生成一集；连续生成两集时第二集收到大纲与第一集；切换集数后数据保持独立。
- E2E 覆盖：首页两个入口、创建第 1/2 集、查看参考剧本、生成结果和错误恢复。
- 最终运行 `npm.cmd run typecheck`、相关 Vitest 测试、Playwright 冒烟和 `npm.cmd run build`。
